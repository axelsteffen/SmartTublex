# SmartTublex

Unofficial Android TV wrapper around the [yuliskov/SmartTube](https://github.com/yuliskov/SmartTube) APK artifact (via apk2maven), with Plex integration through [PlexServiceCore](https://github.com/axelsteffen/PlexServiceCore).

This project is **not** affiliated with or endorsed by the SmartTube author.
